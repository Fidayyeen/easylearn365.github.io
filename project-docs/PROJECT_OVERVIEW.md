# EasyLearn365

## Project Summary

EasyLearn365 is a personal website, technical blog, portfolio, CV, services showcase, and learning-in-public platform.

The project is being built incrementally as a real-world learning exercise to gain practical experience with Git, GitHub, GitHub Pages, DNS, hosting, web development, documentation, and cloud technologies.

## Project Philosophy

Build → Document → Improve

The focus is on learning through practical implementation rather than pursuing perfection from the start.

Every major decision, implementation step, lesson learned, and improvement should be documented.
